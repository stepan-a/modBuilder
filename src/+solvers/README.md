# solvers

Nonlinear Newton solvers with a line search, used by `modBuilder` to close
steady-state equations numerically.

## Overview

The package provides two damped-Newton solvers:

| function | solves | Jacobian |
|----------|--------|----------|
| `solvers.newton` | one scalar equation `f(x) = 0` | automatic (dual numbers) |
| `solvers.newton_system` | a square system `F(x) = 0` | supplied by the caller |

Both are called as `solvers.<name>(...)` (the `+solvers` package folder is a
namespace). `modBuilder.solve` drives the scalar one; `modBuilder.solve_system`
and the block solvers generated by `apply_steady_plan(Solver='newton')` drive the
system one.

## Design: report, do not throw

Every numerical outcome — convergence, non-convergence, a singular Jacobian, a
failed line search — is reported through an integer `flag`, and `(x, fval)`
always hold the **best iterate reached** so the caller can diagnose the failure.
The solvers raise **only** on malformed inputs (caught by their `arguments`
blocks). A caller that needs a solution checks `flag ~= 0` and turns it into a
contextual error — `modBuilder.solve` produces `modBuilder:solve:noConvergence`,
`modBuilder.solve_system` produces `modBuilder:solve_system:noConvergence`.

```matlab
flag  meaning
 0    converged (|f| < tol)
 1    maximum iterations exceeded
 2    singular / non-finite Jacobian or residual
 3    backtracking line search failed
 5    dimension mismatch      (newton_system only)
```

## The iteration

Both solvers share the same damped-Newton structure:

1. **Convergence test first**, at the top of each iteration: exit with `flag = 0`
   as soon as the current residual satisfies `|f(x)| < tol` (scalar) or
   `‖F(x)‖∞ < tol` (system). Testing before the line search lets an iterate that
   is already at the root exit cleanly, without a line search that has no
   headroom below machine epsilon.
2. **Newton step** `dx = −f/f'` (scalar) or `dx = −J \ F` (system). A
   non-finite step — derivative underflow, singular or ill-conditioned Jacobian
   — sets `flag = 2` and stops. The system solver detects singularity by the
   finiteness of `J \ F` rather than an `rcond`/`condest` dispatch, which stays
   cheap and works for sparse Jacobians alike.
3. **Backtracking line search** with an Armijo sufficient-decrease condition on
   `|f|` (scalar) / `‖F‖∞` (system): halve the step from `α = 1` until the
   residual drops by the Armijo margin, down to a floor `α ≥ 1e-10`. No
   sufficient-decrease step (a non-descent direction, or the floor underflowed)
   sets `flag = 3`.
4. **Accept and reuse**: the residual at the accepted point becomes the next
   iteration's starting residual, saving one evaluation per outer iteration.

Because a step is accepted **only** when it strictly reduces the residual, the
residual is monotone across iterations and no separate divergence test is needed.
A final guard promotes `flag = 1` to `flag = 0` when the step accepted on the
last allowed iteration happened to drive the residual below tolerance.

## `solvers.newton(f, x0[, tol, maxit])`

Univariate solver. Differentiation is **automatic** (`autoDiff1`): the unknown is
seeded as a dual number `autoDiff1(x0)`, so one evaluation `f(x_ad)` yields both
the residual and `f'(x)`, and the Newton step is `−r.x / r.dx`. `f` must accept a
scalar (or dual) and return the residual.

```matlab
[x, fval, iter, flag] = solvers.newton(@(z) z^2 - 2, 1);   % x ≈ 1.41421356
```

- `tol` — convergence tolerance (default `1e-6`);
- `maxit` — maximum iterations (default `100`).

## `solvers.newton_system(residual_fn, jacobian_fn, x0[, tol, maxit])`

Square multivariate solver. The caller supplies **both** the residual and the
Jacobian as function handles of the `n×1` iterate — `modBuilder.solve_system`
builds them by automatic differentiation, and the generated steady-state block
routines inline them (residual and analytic or complex-step Jacobian). A residual
of the wrong shape, or a Jacobian that is not `n×n`, sets `flag = 5`.

```matlab
[x, fval, iter, flag] = solvers.newton_system(res, jac, x0);
```

- `tol` — convergence tolerance on `‖F‖∞` (default `1e-6`);
- `maxit` — maximum iterations (default `100`).

## Consumers

- `modBuilder.solve` — solve one equation for one symbol.
- `modBuilder.solve_system` — solve a square system for several symbols
  (parameters, endogenous or exogenous), Jacobian by AD.
- `apply_steady_plan(Solver='newton')` — the damped Newton written into a
  generated `*_ssblock_*.m` routine follows this same design.

See also `../@autoDiff1/README.md` (the differentiation engine behind
`solvers.newton`).
